Desk Helper

A demo of what an app can do on your computer when you let it. Nothing below works until you grant the permission shown on each card. You can answer "no" to any question, and ⌃⌥⌘. stops everything at once.

1. Look at my screen

requires permission: screen

Takes one screenshot (at most 1024 points wide) and lists your open windows. You choose what it sees: the app only suggests its main display, and the loader asks you to pick a display, a window or a region. It gets only what you pick. The picture is sent only to this app's window; anything visible in what you pick can be seen by the app.

2. Point and click (demo)

requires permission: input

A fixed, scripted demo: input.start → move the pointer → click once → input.stop. While it runs, the loader shows its red badge “Desk Helper is controlling your computer — Stop”. The click is real: choose a harmless spot.

3. Type text (demo)

requires permission: input

After a 3 second countdown the text is typed into whichever app has the keyboard focus. Press the button, then click into a text field (a note, an editor) before the countdown ends.

4. Run a tool

requires permission: tool:<id>

Runs one of the host tools you registered (vmapp tool add), with exactly the arguments each pattern allows. There is no shell: ; or $(...) are plain text.


      

    


    

      

        
5. Use an app's MCP tools

        requires permission: mcp:<id>
