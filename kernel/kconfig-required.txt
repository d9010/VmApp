# if any line here does not match exactly. Format, one option per line:
#   CONFIG_NAME=y            built in
#   CONFIG_NAME="string"     exact string value
#   CONFIG_NAME=n            must be off (not set or absent)
# '#' starts a comment. Modules are disabled globally (CONFIG_MODULES is off), so "=m" never appears and is never
# acceptable here.
