# Forbidden kernel options for the vmapp guest (Linux 6.18.y, arm64).
#
# Adapted from d9010-native/guest/distro/kernel/kconfig-forbidden.txt (extended: no namespaces, cgroups, eBPF,
# ext4, overlay, loop or ACPI/EFI, because the vmapp guest uses none of them).
#
# Checked by kernel/check-kconfig.sh against the FINAL .config (after `make olddefconfig`). The kernel build fails
# if any option matching a pattern below is enabled (=y, =m or any value other than n). Format:
#   PATTERN     shell-style pattern matched against the option name without the CONFIG_ prefix; '*' matches any
#               run of [A-Z0-9_]
#   !NAME       exemption: this exact symbol is allowed although a pattern matches it (use sparingly, always with
#               a reason)
# '#' starts a comment. Every non-glob entry must be a real Kconfig symbol of the pinned kernel and every glob must
# match at least one (verified when the kernel source tree is available), so a typo or an upstream rename cannot
# make this list inert.
#
# Network access for apps (a later milestone, SPEC) will need NETDEVICES and a virtual NIC. That change must edit
# this file on purpose, in the same pull request as the spec change.
