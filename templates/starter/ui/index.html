Starter

This window is the UI. Everything it shows comes from the core, a program running in a small sandboxed Linux VM. Each card below is one thing an app can do.

1. Info

Asks the core who it is. Note the Linux kernel and uid 1000: it is not running on your Mac.

2. Your documents folder

Lists a folder you shared when the app was first opened. If you skipped it, the core gets nothing.

    3. Counter

    Saved by the core in its private data folder. Quit and reopen the app: the number stays.

    0

    A native dialog appears. The core can read only the one file you pick, not the folder around it.
