Publish an app

Upload a .vmapp file made with vmapp pack. The server checks every hash in the package before it accepts it.

About you (only for your first publish; optional)

Nothing here is shown to users until you verify it (see Verify your identity). Until then your apps show as "Unverified publisher".

Good to know

  • The first time you publish an app id, you get an owner token. It is shown once and only its hash is stored. Anyone holding it can publish new versions of that id, so keep it private.
  • Versions are immutable and must go up (semver). To fix a mistake, publish a higher version.
  • Everything in the package is public, including the code in core.cpio.
  • You can also use the command line: vmapp publish app.vmapp.
  • Publishers start as unverified. You can verify an email address, and then a domain you control, on the Verify your identity page. Users only ever see verified facts.
  • The registry does not review apps. Users see the permissions your app asks for and decide.
Downloads are counted per address and version once a day; the registry keeps no addresses.
