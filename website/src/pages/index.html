title: Home description: D9010 VmApp runs desktop apps in their own small virtual machine, so an app can only touch the folders and websites you allow. Open source, for macOS. ---

Open source · macOS on Apple silicon

Run apps you don't have to trust.

A normal app acts as you: it can read your files and talk to any server. {{name}} takes that back. Each app runs in its own small virtual machine, and you decide which folders and which websites it can reach. Nothing, by default.

How it worksRead the documentationView on GitHub
01

A sealed room per app

The app's engine runs in its own tiny VM. It starts in about half a second and sees only what you hand in.

02

A window with no reach

The app's screen is drawn natively on your desktop, with no internet and no file access of its own.

03

You hold the keys

The launcher asks which folders and which websites, shows every message an app sends, and lets you revoke access at any time.

How an app is split

Every app has two halves that never touch each other directly. All messages go through the launcher, which is the one piece of trusted code on your Mac and is the same for every app.
