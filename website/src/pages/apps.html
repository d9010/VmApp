Samples

Apps that run in the launcher

These samples ship with the launcher. They are real apps, chosen to show different languages and different levels of access. Under each one is the full list of what it asks for. Everything else stays out of reach.

How apps get onto your Mac. You install apps from inside the D9010 VmApp Launcher (File → Load examples, or Install from file), where the permission sheet shows you what each app wants before it runs. This website deliberately has no download buttons for apps: the launcher is the front door, so you always see the permissions first.

An app catalog is coming

A public catalog is built and will open later. It will let you search and browse apps, see what is popular, and read what each one asks for before you install. Anyone will be able to publish: every version is kept, a bad release can be withdrawn with a reason, and users choose whether to stay on a version or follow updates. Apps will be fetched by the launcher itself, so the permission sheet always comes first. See the roadmap.
